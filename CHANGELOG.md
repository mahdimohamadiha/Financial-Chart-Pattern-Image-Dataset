# Changelog

All notable changes to the Financial Chart Pattern Image Dataset are documented here.

## [1.0.0] - 2026-10-05

### Added
- Initial dataset release.
- Four financial chart-pattern classes.
- 300 images per class.
- 1,200 images in total.
- 18 Forex currency pairs.
- Four timeframes: 1D, 4H, 1H, and 15M.
- 72 currency-pair/timeframe combinations.
- 224 × 224 pixel candlestick chart images.
- Dataset documentation and metadata.
- Citation information.
- Source attribution information.
- Private research-collaboration terms.
